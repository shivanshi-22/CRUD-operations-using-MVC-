# CRUD Operations using MVC
This project implements basic CRUD (Create, Read, Update, Delete) operations using the Model-View-Controller (MVC) design pattern. It provides a structured and modular approach for managing data and presenting it in a web application.

# FEATURES 
1.CRUD Functionality: 
Perform create, read, update, and delete operations.
2.MVC Architecture:
Separation of concerns for scalability and maintainability.
3.MongoDB Integration:
Database for storing and managing data.
4.Node.js Backend: 
Implements business logic and handles requests.
5.Dockerized Setup: 
Simplified deployment using Docker and Docker Compose.

# Technologies Used
Backend: Node.js, Express.js
Database: MongoDB
Frontend: HTML, CSS, JavaScript
Containerization: Docker
